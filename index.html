QUICK ANSWERS

Everything you
need to know.

Common questions about registration, saved events, participation and this prototype.

Is this portal connected to a live IEM database?+

This submission is a front-end prototype. Registrations, saved events and proposals are demonstrated with browser local storage rather than a production server.

Can I register for more than one event?+

Yes. Each completed registration is stored as a separate pass in the demo dashboard.

How does the event countdown work?+

The hero automatically finds the nearest future event from the built-in event calendar and updates the countdown every second.

Can students save events for later?+

Yes. Use the star button on an event card. Saved events remain available after refreshing the page on the same browser.

How could this become a production system?+

A backend API, authentication, database, admin approval workflow, real email verification and a proper event-management dashboard can be connected without redesigning the front-end.

What happens when I save an event?+

The event title is stored in local browser storage, the star state updates immediately, and the event appears in My Schedule until you remove it or clear local data.

Can organizers submit multiple proposals?+

Yes. Each proposal gets a demo proposal ID and is stored locally so the workflow can be demonstrated without a server.

What is included in the event pass?+

The demo pass includes a unique ticket code, participant name, roll number, department, selected role and event date. It can also be printed or saved as a PDF.

Does the interface work on mobile?+

Yes. The navigation, event cards, forms, dashboard and modal interactions are designed to collapse into a single-column mobile layout.
